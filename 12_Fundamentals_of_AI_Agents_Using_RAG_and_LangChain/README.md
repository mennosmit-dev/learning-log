# Fundamentals of AI Agents Using RAG & LangChain – Project Implementations

This folder contains Retrieval-Augmented Generation (RAG) and AI agent experiments 
developed during the **IBM AI Engineering Professional Certificate**.

The focus of this module was building context-aware LLM applications using LangChain, 
embedding-based retrieval, and modular agent workflows.

---

## 🧠 Overview

Key areas explored:

- Retrieval-Augmented Generation (RAG) pipelines
- Prompt engineering and in-context learning
- LangChain chains, agents, and modular workflows
- Embedding-based retrieval with FAISS
- Practical AI agent design

These projects extend transformer fine-tuning and alignment work toward 
production-oriented LLM applications.

---

## 📂 Selected Implementations

### 🔹 RAG Systems

- `rag_hr_policy_qa.py`  
  Built a DPR + GPT-2 RAG pipeline for HR policy question answering.  
  Answers questions from retrieved policy documents.

- `rag_song_filter.py`  
  Developed a RAG-based moderation system assessing song appropriateness for children.  
  Improved retrieval accuracy while reducing reliance on full LLM inference.

### 🔹 Prompt Engineering & LangChain Workflows

- `prompt_engineering_langchain.py`  
  Implemented structured prompt templates and in-context learning strategies.  

- `langchain_framework_demo.py`  
  Built modular LLM applications using LangChain chains and agents.  
  Enabled dynamic workflows, model switching, and external data integration.
